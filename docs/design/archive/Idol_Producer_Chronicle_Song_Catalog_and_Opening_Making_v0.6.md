## 统一歌曲数据模型
song_id / title_ja / title_zh / work_kind(original or cover) / inspiration_tag(non-visible) / original_group_size / intrinsic_palette_8 (independent numeric weights, red/orange/yellow/aqua/green/blue/purple/pink) / appeal / vocal_difficulty / dance_difficulty / bpm(optional) / duration_seconds / theme_tags / song_status / arrangement_variant / formation & lead assignments / formation_familiarity / performance_history.

- Song 固有 Palette 与队伍的 Presented Palette 不同；卡片/列表展示固有 Palette 的简洁色条，Detail 加上实际演绎 Palette 及队员站位/Part（只有训练/演出后存在）。
- appeal 为作品基本吸引力，不等于每次现场实际 Impression；本轮用 0–100 暂定编辑标尺，等映射到正式 Song Appeal 体系后统一。
- Vocal / Dance Difficulty 用 0–20，职业偶像歌曲普通难度约 12，开局候选多在 9–15。
- **原版人数**是歌曲原编制的可用参考，不等于玩家必须采用相同人数；翻唱需要额外适配编舞和 Part，调整可能带来 Familiarity 损失。
- 所有歌名是原创虚构标题；不照搬 AKB48、坂道或其他真实歌曲名、歌词或曲调，风格灵感不建立直接授权关系。

## 三种视图
- Card：封面/名称/类型、主要单色标记（双色歌显示两个色块）、appeal、声乐和舞蹈难度、原版人数、翻唱剩余授权天数/年价；可加入选曲清单。
- List：紧凑排序和多选，支持 Appeal、Difficulties、人数、费用、Palette 和是否已授权的过滤；底部显示「已选 N 首／莉奈建议 6 首」、总费用与出道 Setlist 的预计空缺；不锁死第六首后的继续选择。
- Detail：作品身份、完整八色固有 Palette、Theme/Appeal、双难度、原版人数、时长、合同许可、翻唱履历及版本演绎信息，所有字段来自同一 song_id。

## 翻唱费用与权利分层
游戏合同使用 `cover_arrangement_and_rehearsal_license` 模型：每曲一次支付价格、可在本游戏内演出一年，授权剩余期限写入玩家存档；到期续费才继续使用。其价格是**模拟商业合同设计值**，并非 JASRAC/日本实际统一年费。
另记现场公演的 `public_performance_royalty`，由场馆/主办或团队依据演出合同缴纳，避免重复扣费。如果游戏使用既有商业母带、录像发布或制作改编，则需要额外权利，不视为上述年费覆盖。现实 JASRAC 对编曲和母带通常不一揽子授权，不能把游戏简化数字解释为真实报价。

## 经济与排期触发
- 莉奈建议 6 首，UI 不使用强制 `6/6` 或「未选满无法确认」；玩家选择少于或多于六首时，Staff 根据已训练可演出曲目数、原创交付时间和五月八曲方案动态给出风险提示。候选一旦确认，年期从授权生效日算，过期不可在 Live Setlist 中选用。
- 每首 cover 需要 Learning 任务；与原版人数差距会影响分配难度但不直接罚能力。
- 原创制作 4–8 周基准，外部音乐制作的报价沿用每首 ¥180,000 的待平衡值，不包含录制成本不可证实的细项。
- 学校和未成年晚间限制持续生效；排练消耗场地时间，三位创始成员负责指导而非零成本外聘教师。
- 始终保留原始属性、作品固定 Palette 和版本 Presented Palette 三层区别。

## 选曲会议对话（开局）

> 星野莉奈：「最初はカバーを六曲くらい用意しておくと、対バンにも対応しやすいと思う。でも、予算や練習時間もあるし、最後はプロデューサーが決めてね。」

操作规则：莉奈的建议作为默认预选方案，可一键采用、逐首替换或完全清空；所有变更实时反馈授权预算、所需排练量与三月底可演曲数。对于玩家只选三首的方案，不禁止签约，但提醒五月之前需要继续采购或调整出道演出方案。对于八首或更多翻唱，提醒训练排期可能更紧且成本增加。
