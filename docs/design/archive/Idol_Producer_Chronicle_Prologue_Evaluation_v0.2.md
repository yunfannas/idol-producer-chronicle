# Idol Producer: Chronicle — 序章结算评价 v0.2

**状态：设计稿。代替 v0.1 的公开数字评分与维度命名。**

## 时间及规则

2014 年 8 月 TIF 演出完成后展示序章回顾。2013 年 5 月出道、2013 年 12 月定期公演合作、2014 年 7 月首次 One-man、2014 年 8 月 TIF 均为剧情保障的**机会**，不是保障动员、演出成绩或收入。任何评级都可继续下一章，不触发序章 Bad End；实际现金、贷款、资产及成员状态照常继承。

## 仅使用评级的四个维度

结算画面中**不出现任何数字总分、单项数值或百分比进度条**。四维各显示 S / A / B / C / D / E 之一；综合评价也只显示一个评级。可以在内部使用配置化的连续统计量和阈值计算评级，**这些中间数值不得出现在结算 UI**。

1. **Fans / 粉丝基础**：稳定现场动员、复购与留存、Core/Otaku 积累、Public 认知及特典会结果。勿因一次 TIF 外部流量直接当作忠实粉丝；可举实际场次和可观察的行为为依据。
2. **Performance / 舞台表现**：实际 Live Impression 相对预期、观众满意度、稳定性、歌曲与演出的契合，以及原创歌曲**制作质量转化成的演出加成**、编排与排练完成度。制作了歌曲不自动高评价；要真正表演并产生效果。不能因为剧情保送 One-man / TIF 而加分。
3. **Members / 成员发展**：成员能力相对入团时的成长、Trait 积累、培训、团队熟练度、Leader 发展、Familiarity / Admire 关系与冲突处理。高初始能力不当作成长贡献；不强迫和谐满值。
4. **Operations / 运营水平**：现金流、债务偿还能力、合同与费用管理、经营韧性、原创歌曲资产与曲库授权权益、长期排练场地（例如**签下的练舞室**）、定期公演合作等可用资源。资产按当前仍可利用的权益与未来效用评价，不把每笔制作费直接等于资产价值。

### 同一制作行为的不同出口

- **Performance** 看歌曲制作质量怎样成为真实舞台 Impression 与观众体验；
- **Operations** 看已取得歌曲使用权、完成品、档期和场地合同等能否持续支持团队经营；
- **Members** 看成员通过制作与训练获得的个人成长；
- **Fans** 看观众是否因此形成稳定关注。

不同维度读取各自的**实际结果**；不得仅凭“购买一首歌”在四项中重复加满评价。

## 综合评级

- 初版四维等重要性，内部按统一、可配置的分档规则汇总，**仅输出 S/A/B/C/D/E**；不展示隐藏加权分。
- 建议先用评级序位做基线：S=5、A=4、B=3、C=2、D=1、E=0（仅内部）。取四项的平均序位并按就近等级映射；边界和极端不均衡存档的处理通过试玩调整。内部序位不是玩家可见“总分”。
- 结算有四个可展开的证据摘要：引用本存档的 Live、歌曲、成员、Finance/Asset Ledger 记录，说明为什么得到该等级。
- **B 是历史路线参考级别**，需要用可核实的 2013–2014 年现实轨迹校准，不主张现实人物存在准确的内部四项成绩。
- 本章评级与世界模拟的 Live/Music/Brand **Group Tier 完全独立**，不能相互替换。

## 显示范例（仅 UI 预览，非测试结果）

| 结算条目 | 等级 | 解释方向 |
|---|---|---|
| 粉丝基础 | C | 一定数量重复到场，但稳定动员仍在培育 |
| 舞台表现 | B | 原创歌曲已经转化为有效演出，整体稳定性尚有空间 |
| 成员发展 | A | 新人成长明显，合作关系逐步成熟 |
| 运营水平 | B | 现金可控，积累歌曲和固定练舞资源，同时仍有贷款 |
| **综合评价** | **B** | 2013–2014 的稳健起步 |

## UI 与剧情

结算主画面：标题、综合大字母、四张定性评级卡片、可展开的存档证据、回顾时间线和「进入下一章」。**不用数值雷达图和进度条**，避免暗示精确分数。由 2014 年 TIF 当时在籍的 Leader 主持，不让已毕业的星野莉奈默认出场主持。不同等级只影响总结语气、下一章资源和人际基础的既有事实，不强制分支为 Bad End。
