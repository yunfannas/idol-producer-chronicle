# AKSB 序章角色美术规范与人员表 v1.2

状态：设计工作稿（2026-10-26）。本文件专用于 Chronicle 的 AKSB 序章；史实原型与虚构游戏角色分离，甄选者映射待核的不得标成已确认。

## 已锁定

- 序章全体角色：**一张常服全身立绘 + 一张全身舞台立绘；头像一律从对应全身立绘自动裁切**；常服／舞台头像均为衍生图，不能单独生成另一张脸。
- 全身立绘 **1024 × 1536 PNG**；头像 **512 × 512 PNG**，纯白或无干扰浅色背景。
- **序章仅一套舞台演出服系列**：2013 年制服式白色主体、淡蓝色修饰、简洁短裙。允许领结、细纹样、裙边、袖口、发饰小幅差异；禁止大裙后蝴蝶结、繁复层叠荷叶边及近年华丽礼服式设计。
- **序章不设正式成员色**。横山利奈早期设想的颜色分配不可等同于最终选拔后的正式担当色；服装颜色不得回写 `member_color`。
- 人物统一日系偶像插画的线条、肤色、柔和上色和头身比例；不统一脸型、角度、表情和站姿。参考已通过的星野莉奈定稿及 HEROINES 三人画风参照。
- 出道/1st one-man 采用上述制服感演出服；**第一章 CD 发售／2nd one-man 才改用浅蓝色统一制服**。

### 画布、基准线与像素映射

- 所有全身图使用 `1024×1536`，统一**地面鞋底基准线**；没有每人自动裁掉顶部空白的紧裁切。
- 采用真人原型身高的**相同比例**对齐，不是人为划分 tall/medium/short 档。以最高的 163 cm 作为初步校准值；可先用 `full_height_px = 1320 × height_cm / 163`，脚底统一放在 `y=1470`，头顶 `y=1470-full_height_px`。此处系绘制校准参数（鞋跟、头饰及姿势使视觉顶部不同），不是角色身高数据。
- 按此近似值，153 cm 与 163 cm 的头顶差约 **81 px**；155 cm 与 162 cm 差约 **57 px**；158 cm 与 153 cm 差约 **40 px**。所有角色相同视角、平底/等高鞋基准下，差异才成立。
- 弯膝、叉脚、抬脚、夸张手势会改变可见高度，应保存角色的**直立等效高度**，并在排列测试图中优先使用标准站立参考，不能为了“显矮”拉短小腿或为了“显高”扭曲头身比例。
- 星野新全身图目前仍为候选修订稿，需与宫原 162 cm、小日向 160 cm 在同一鞋底线排版后验收，不能单张凭空判定大小。
- 将上述 `height_cm` 记录于角色表，不再采用之前主观的高矮分组。

### 生成与验收硬约束

1. **先锁定每人头部设计**：按脸型轮廓→眼距→眼型→眼皮/眼尾→眉→鼻口→头发的顺序确认；不是用一个基础脸换头发。
2. **两组混淆风险专门验收**：小日向 vs 成瀬、 小日向 vs 藤咲、星野 vs 藤咲。尤其陽菜没有发饰、脸型长且眼窄下垂；瑠菜胸口中长侧分发、小白花发夹、较圆明亮的眼、脸更圆、头端正；藤咲一层齐刘海、黑长直、153 cm 幼态脸。
3. **各自常服立绘单独生成**，无文字白底，之后自动裁切同一人 `512×512` 头像（不再次重绘眼睛）；演出服立绘继承完全相同的五官、发型、身高，动作和表情允许比常服稍大，但身体朝向仍控制在约 0–20°，便于合照。
4. **高度严格按表中厘米数**，同 1024×1536 画布、同一鞋底线；153 cm 角色比 163 cm 多留头顶空间。常服鞋跟高度需要折算，不能靠歪头/屈膝误造高矮。
5. 首批九宫格、八人长图属于**视觉方向/排布预览而非独立可用素材**；此前重复生成导致其他人意外改变，禁止用重新生成全员合照来修复单个角色。
6. 所有单人立绘需做**去发饰＋同发色灰度脸部裁切对比**：若两张脸依然如复制品则退回修改。
7. 衣装时代感为 2013 年早期日本偶像企划；早期常服自然、不过分 2020s 设计；序章舞台制服白＋浅蓝、少花边。2018 年插画师参考只用于造型辨识和插画表现，不改写场景历史时代。

## 美术验收

1. 全身图完整显示头、手、鞋，无裁切；头像 64×64 缩小时仍具有辨识度。
2. 共用同一演出服轮廓；饰物差异有限；拒绝混入近年复杂打歌服风格。
3. 三人并排避免同脸、同歪头、同姿势；星野萌系双马尾，宮原浅发轻辣妹，小日向黑长直温柔。
4. 身份对应与剧情人数在正式批量生产前依据 Chronicle 场景数据核验。
5. 图片二进制资源只有在上传并验证 GitHub 文件存在后才标记为 `in_repo`。
