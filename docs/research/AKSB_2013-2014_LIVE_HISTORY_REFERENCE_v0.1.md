# AKSB 2013–2014 历史 Live / Event 参考表 v0.1

> 研究资料，非 Chronicle 游戏事件脚本；整理于 2026-10-24。范围：2013-05 至 2014-08。非完整演出日历。所有人数、收入、特典会销售如无来源均留空；不以拼盘总动员代替 AKSB 自身动员。

## 证据标准

- **A**：同期成员公告／回顾、主办票务或当事共演者演出档案明确点名 AKSB。**注意**：事前公告只能确认计划，不保证演出实际完成；已结合事后记录者另注。
- **B**：较可靠后期媒体回顾、同期活动的预告与后期记录组合；具体日期仍可能冲突。
- **C**：仅二手年表、未复核的搜索线索；不能直接作为固定剧情或计入已确认场次数。
- **衍生单位**：オムライス女等可能只是部分成员，不能自动等同 AKSB 全团出演。

## 已知规律与 Chronicle 用法（设计推论，不是历史事实）

1. 2013-05 赤坂BLITZ 为大型拼盘出道，不能将全场观众或门票收入视为 AKSB 自有。游戏的千人以上整场到场数属于剧本设定，非已核实历史实数。
2. 2013-06 至 12 月 TwinBox 的重复系列拼盘是重要业务联系；**重复邀约 ≠ 团体自主定期公演**。
3. 2013-07-30 当事档案明确写『メンバー選抜』；少量成员嘉宾、衍生单位需与全团演出分开统计。
4. 2013-09-29 免费商业设施 Live 是『新观众接触→握手／特典会』的优质历史参考；不能据此推断具体 Cheki 营业额。
5. 2014-01 已有定期公演计划，2014-03-05 明确『再開』。1月15日首场及中断原因目前只有二手材料，不应写死成强制剧情。
6. 2014-04-16 りなはむ公布毕业；2014-05-11 特别公演。人物真实职业动机可参照本人原话，但 Chronicle 的莉奈采用独立虚构剧情。
7. 2014-07 首次 One-man 的 7/20、7/21、7/25 资料冲突；当前只锁定『7月、300人以上』。
8. 2014-08-02 TIF 演出确认；多舞台／具体特典会尚未完整核对。
